1. INTRODUCTION                                              *mrview-intro*

mrview points gitsigns at the merge-base of the current branch and the MR
target, so the changed lines of the MR are marked in normal buffers. In
structural mode the marks come from difftastic (`difft --display=json`):
lines that changed only in formatting are dimmed, deleted lines are shown as
virtual lines, and a side-by-side pane shows the base version.

Reviewed marks and the chosen target are stored in a JSON file in the git
common directory.

Requirements: Neovim >= 0.11, gitsigns.nvim, snacks.nvim (pickers), `difft`
0.70 or 0.71 (structural mode). Run |:checkhealth| `mrview`.

==============================================================================
2. COMMANDS                                                  *mrview-commands*

                                                             *:MRView*
:MRView {sub} [target]

  on          Review against the merge-base with the target.
  structural  Same, with difftastic signs.
  off         Leave review mode.
  base        Pick the target branch. Text that matches no branch is
              taken as a revision, e.g. HEAD~1 or a hash.
  files       Picker of changed files with reviewed marks (✓ reviewed,
              ~ changed since marked).
  commits     Picker of MR commits; selecting one enters commit mode,
              which detaches HEAD at that commit.
  next        Next commit in commit mode.
  prev        Previous commit in commit mode.
  reviewed    Toggle the reviewed mark of the current file.
  since       Diff the current file against the commit it was reviewed at.
  deleted     Toggle deleted lines (structural mode).
  split       Toggle the side-by-side base pane (structural mode).

`on`, `structural`, `files`, `reviewed` and `since` take an optional target.

Lua functions with the same actions: `require("mrview").on()`,
`structural()`, `off()`, `base()`, `files()`, `commits()`, `next_commit()`,
`prev_commit()`, `toggle_reviewed()`, `since_review()`,
`nav("next"|"prev")`, `toggle_deleted()`, `toggle_split()`.

==============================================================================
3. CONFIGURATION                                             *mrview-config*

`setup()` is optional. Defaults: >lua
    require("mrview").setup({
        remote = "origin",
        targets = { "main", "master" },
        difft = { cmd = "difft", debounce_ms = 300 },
    })
<
==============================================================================
4. HIGHLIGHTS                                                *mrview-highlights*

  StructDiffFormat        Lines changed only in formatting (NonText)
  StructDiffAddInline     Added tokens (DiffAdd)
  StructDiffChangeInline  Changed tokens (DiffAdd)
  StructDiffDeleteInline  Deleted tokens (DiffDelete)

Line signs reuse GitSignsAdd, GitSignsChange and GitSignsDelete.

==============================================================================
5. LIMITATIONS                                               *mrview-limitations*

- difftastic JSON output is unstable and needs `DFT_UNSTABLE=yes`.
- Commit mode checks out commits with a detached HEAD and refuses to start
  while tracked files have uncommitted changes.
- No forge integration.
